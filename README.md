# Cupid's Calling — trình chiếu

Trang trình chiếu cho sự kiện Cupid's Calling (Newway Realty): nền KV,
logo hai góc, slide Canva nhúng ở giữa.

- Lật trang: phím ← → / PageUp PageDown / bút bấm slide, hoặc bấm chuột lên slide
  (1/3 bên trái = lùi).
- Toàn màn hình: nút góc phải hoặc phím F (Esc để thoát).
- Bỏ qua trang: mặc định bỏ trang 2–13 trong 69 trang. Đổi qua địa chỉ:
  `?bo=2-13,20,25-27&tong=69`
